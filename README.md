# YUJIN FLOW

이유진의 120분 Agent Workflow Lab.

강의 사이트: https://leeyoojinwork-pm.github.io/yujin-flow/

## Deployment

GitHub Actions deploys only `public/` to GitHub Pages on pushes to `main`.
Open `public/index.html` to use the deck locally without a build step.

## Worksheet Data

Worksheet answers remain in the visitor's browser localStorage. This static
site does not send answers to a server or AI API. Tabs on the same site in the
same browser profile share saved answers. Copy and Markdown downloads run locally.

Animations demonstrate workflows; they do not execute AI agents or shell commands.

## Personal Agent Lab

Page 26 connects each learner's problem to Project instructions, first-run requests,
and reusable Skills. Import fills empty fields only. The instructor's lecture-deck
Agent demo is a separate downloadable kit and never overwrites learner answers.
Page 2 includes flowing output highlights with pause and reduced-motion support.

## Five YUJIN Assignments

The framework links directly to problem.md, job-story.md, workflow.md,
boundaries.md, and SKILL.md. Each assignment includes earlier design answers
and offers Markdown download and next-assignment navigation. The notebook groups
the existing worksheets into Y/U/J/I/N without changing stored answer IDs.
The five-MD archive is for design backup; use the separate Skill ZIP for upload.

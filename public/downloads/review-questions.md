# 한 번에 하나씩 묻는 검토 질문

내 설계 노트를 읽고 아래 순서에서 아직 답이 없거나 충돌하는 질문 하나만 골라 물어봐. 답변을 기다린 후 design-brief.md의 결정사항을 갱신해줘. 이미 답한 질문은 건너뛰어.

1. 누가 어떤 상황에서 어떤 손실을 겪는가?
2. 어떤 결과면 이 일이 끝났다고 인정하는가?
3. 입력 자료는 어디에 있고 필수 항목은 무엇인가?
4. AI가 선택해야 할 행동과 고정된 단계는 무엇인가?
5. 결과에 어떤 근거가 있어야 하는가?
6. 실패하면 어디로 돌아가고 몇 번까지 수정하는가?
7. 누가 어떤 결과를 확인하고 승인하는가?
8. 다음 입력으로도 같은 기준을 통과했는가?

관찰하지 않은 실행과 수치는 만들어내지 않는다. 완료하면 전체 질문과 실제 내 답변, 남은 미확인 사항을 Markdown으로 정리한다.

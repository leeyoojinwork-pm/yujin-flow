## 9. HTML/PDF 변환 요청
Claude에게 보고서를 정리시킬 때는 아래 조건을 붙입니다.

- single-file HTML로 작성한다.
- A4 세로 PDF로 인쇄해도 깨지지 않게 @media print를 포함한다.
- 업무 순서도는 CSS grid/flex와 선으로 구현한다.
- Mermaid, CDN, 외부 폰트, 외부 이미지에 의존하지 않는다.
- 표와 순서도 내용이 서로 다르면 표를 기준으로 고친다.
- 확인하지 않은 효과, 수치, 실행 결과를 만들지 않는다.
